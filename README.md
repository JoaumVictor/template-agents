# 🤖 Template Agents

Bem-vindo ao repositório central dos **Agentes de IA**! 🚀

A ideia principal deste repositório é servir como um **template base** para a pasta `.agents`. Assim, você pode sempre clonar ou atualizar este repositório para garantir que seus projetos tenham a versão mais recente dos workflows, regras e prompts de IA.

## 🎯 Objetivo

Manter um padrão de alta qualidade, segurança e produtividade em todos os seus projetos. Com este template, você garante que as **Regras de Ouro** (como zero secrets, clean code e padrões de commit) e os **Workflows** customizados (`/analyze`, `/propose`, `/dev`, etc.) estejam sempre atualizados e prontos para uso em qualquer nova base de código.

## 🚀 Como utilizar

Sempre que iniciar um novo projeto ou quiser atualizar os agentes de um projeto existente:

1. **Clone este repositório** (ou faça um `git pull` para pegar as últimas atualizações).
2. **Copie a pasta `.agents`** deste repositório para a raiz do seu projeto.
3. Pronto! Sua IDE e seus agentes de IA já estarão configurados com todo o contexto, regras e fluxos de trabalho avançados.

## 📂 O que tem na pasta `.agents`?

- `workflows/`: Fluxos passo a passo para tarefas comuns (como criar features, refatorar código, fazer commits).
- `rules/`: Regras de sistema rigorosas que a IA deve seguir (idioma, segurança, padrões de projeto).
- `history/`: Estrutura de memória para a IA não perder o contexto do que foi feito recentemente.
- `README.md`: Documentação específica interna da pasta detalhando os comandos disponíveis.
